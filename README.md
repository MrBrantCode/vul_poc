# Vulnerability PoC Archive

## Purpose

This repository records vulnerability findings identified during security research, including vulnerability reports, proof-of-concept materials, reproduction notes and supporting screenshots.

The primary goal is documentation and tracking of verified issues for research, coordinated disclosure and future reference.

## Disclosure Standard

Materials are included here after the vulnerability has been reported to the vendor or maintainer.

- If the vendor has fixed the issue or confirmed that a fix has been released, the fix status is recorded in the corresponding project README and Disclosure_Process.md.
- If a report is still pending vendor confirmation or a fix, this is explicitly stated in the project README. Such entries are published only after responsible reporting and with a coordinated disclosure window.

This repository is not intended to provide weaponized exploit content. It documents verified issues in a structured form for research and disclosure follow-up.
