# ruoyi-vue-pro vulnerabilities

- Repository: https://github.com/YunaiV/ruoyi-vue-pro
- Affected version: master branch before 2026-11-05 (c799e27c54 at the time of reporting)
- Vendor status: confirmed and fixed on master-jdk17 (2026-11-05); default master branch sync pending
- Disclosure status: CVE request pending (not assigned yet)

- admin_token_revocation/ - admin account invalidation does not revoke tokens (YD-2)
- brokerage_withdrawal_race/ - concurrent brokerage withdrawal (YD-3)
